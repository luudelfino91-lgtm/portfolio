# Identidade visual

Paleta extraída da foto de perfil (tons de orquídea, ameixa e meia-noite), sem marrons. Clean, inspirada em portfólios de BI com foco sutil no visual dos projetos.

## Cores (tema claro)

| Token | Hex | Uso |
|---|---|---|
| `--ink` / `--midnight` | `#191328` | Texto principal, botões escuros, bloco de contato |
| `--plum` | `#8A3D86` | Cor de destaque (links, CTA, marcadores) |
| `--orchid` | `#CD9CDA` | Acento suave, marca, elementos gráficos |
| `--orchid-soft` | `#F3E7F7` | Fundos de etiquetas e contadores |
| `--bg` | `#FBFAFD` | Fundo da página (branco levemente lilás) |
| `--line` | `#E7DFEC` | Bordas e divisórias |

O tema escuro redefine os mesmos tokens em `styles.css` (`prefers-color-scheme` e `[data-theme="dark"]`). Estilize sempre pelos tokens, nunca com cores fixas.

## Tipografia

- **Poppins** — família única: títulos e números de destaque em SemiBold/Bold (600/700); texto corrido e interface em Regular/Medium (400/500). Substitui Bricolage Grotesque + Figtree, descartadas por soarem informais demais para a marca.
- **JetBrains Mono** — rótulos técnicos, nomes de arquivo, datas

## Marca
