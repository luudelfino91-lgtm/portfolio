SQL playground

Write SQL and run it on a sample database that lives in this browser tab. Pick one of five built-in scenarios (sales, digital marketing, logistics, HR or customer service). Nothing is uploaded: the data comes with the site and your queries stay on this device.

Ready to practise? Go to the five guided exercises

Sample databases

Each scenario is a made-up database with related tables. All data is fictional. Choose a scenario, load it, and practise SELECT, JOINs and GROUP BY. The five guided exercises below use the Sales scenario.

Loading replaces the tables of the sample databases that are in this tab (changes you made to them are lost); tables you created with other names are kept. After Stop or a time limit the loaded database is reloaded automatically. Reset database removes everything.

Sample queries

Choose a query to put it in the editor. It does not run by itself: read it, change it if you like, then press Run. The queries follow the scenario selected above; load that scenario first.

    Exercises

    Five guided exercises on the Sales sample database, from easy to harder. Write your query in the box, press Check, and the page tells you whether your result matches the expected one. They work only with the Sales scenario; exercises for the other scenarios are planned.

    How it is checked: your result is compared with the expected result. Columns must match by position and name (upper or lower case does not matter). Numbers are equal when numerically equal (3 and 3.0 are the same; decimals allow a tiny tolerance) and NULL only equals NULL. Row order only matters when the exercise asks for ORDER BY. Your own tables are not touched: the check runs on a fresh private copy of the sample database. Progress lives only in this page and is lost when you reload.
