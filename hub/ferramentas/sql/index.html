SQL playground

Write SQL and run it on a database that lives in this browser tab. You can load your own CSV files as tables. Nothing is uploaded: the files and the queries stay on this device.

Ready to practise? Go to the five guided exercises

Sample database

A made-up online shop with five related tables: clientes, categorias, produtos, pedidos and itens_pedido. All data is fictional. Use it to practise SELECT, JOINs and GROUP BY.

Loading it again replaces the five sample tables with a fresh copy (changes you made to them are lost). After Stop or a time limit it is reloaded automatically. Reset database removes everything.

Sample queries

Choose a query to put it in the editor. It does not run by itself: read it, change it if you like, then press Run. Load the sample database first.

    Exercises

    Five guided exercises on the sample database, from easy to harder. Write your query in the box, press Check, and the page tells you whether your result matches the expected one.

    How it is checked: your result is compared with the expected result. Columns must match by position and name (upper or lower case does not matter). Numbers are equal when numerically equal (3 and 3.0 are the same; decimals allow a tiny tolerance) and NULL only equals NULL. Row order only matters when the exercise asks for ORDER BY. Your own tables are not touched: the check runs on a fresh private copy of the sample database. Progress lives only in this page and is lost when you reload.
