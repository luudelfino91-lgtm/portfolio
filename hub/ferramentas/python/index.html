Python playground

Write Python and run it in this browser tab. The code runs in an isolated frame that cannot reach the internet, this page or your other data.

Privacy: your code, your files and the output never leave this browser. Nothing is sent to any server, and nothing is saved.

Code

Press Ctrl+Enter (Cmd+Enter on a Mac) to run. The Tab key moves focus out of the editor.

Python is not downloaded until you press Run. The first run downloads about 6 MB (again each time you open this page, because the isolated frame cannot reuse the browser cache) and takes a few seconds.

Limits: code up to 200 KB; output up to 2,000 lines or 256 KiB (the rest is discarded); memory up to 4 GiB (on phones the browser may close the tab sooner). Variables do not persist between runs; Stop and the time limit end the session and Python reloads on the next Run.

CSV file (optional)

Limit: 10 MB. The file appears inside Python as /data/ followed by its name; read it with open() or the csv module. pandas is not included.
