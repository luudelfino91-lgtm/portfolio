Privacy

Short and honest: what this Hub does with your data.

Your data stays in your browser

The Hub is a set of static pages. It has no server that receives files or queries, and it asks for no account. There is no file upload anywhere: the data explorer, the SQL playground and the Python playground work only on five sample datasets that come with the site itself, and your code and queries are processed in your browser and are not sent anywhere. These statements are provisional until the final privacy review.

Cookies and tracking

Hub pages set no cookies and include no analytics, advertising or tracking scripts.

What is stored on your device

Only two small preferences, kept in your browser’s localStorage and never sent anywhere:

  • ld-lang your language choice (en or pt), shared with the portfolio.
  • ld-theme your theme choice (light or dark), shared with the portfolio.

You can remove both at any time in your browser settings.

Python playground

The Python playground also runs in your browser. There is no file upload: the only data it can read are the tables of the sample scenario you choose, copied from this site into an isolated frame of the page. Your code never leaves your device and is not sent to any server.

Python itself (about 6 MB) is downloaded from this site’s own files, not from a third party, and only when you press Run, not when the page opens. Nothing is saved: the code and the output are gone when you close or reload the page; the only things kept on your device are the language and theme preferences above.

This describes what the page does and it was tested only in Chrome. Before running any code the tool checks that the browser blocks network access and eval inside the isolated frame, and refuses to run if it cannot confirm that.

Fonts and third parties

Hub pages serve their fonts from this site and make no requests to other domains.

The portfolio is a separate part of the site and still loads its fonts from Google Fonts. Go to the portfolio
